# What should an OSSF preparation checklist establish?

> A useful worksheet identifies missing information and records to request. The permitting authority and qualified professionals establish requirements for the actual parcel and work.

This reference supports the [Out West Septic generator](../scripts/outwestseptic_permit_checklist.py). It was prepared with automated assistance for the [Out West Septic](https://outwestseptic.com) project. No professional authorship, business license or completed-job history is asserted.

Sources reviewed **2026-10-18**. The generator operates offline and does not refresh these links when run.

## Evidence behind the workflow

| Worksheet concern | Primary source and scope |
| --- | --- |
| Authority, application and evaluation | [TCEQ permit guidance](https://www.tceq.texas.gov/permitting/ossf/ossfpermits.html) identifies the authority lookup, planning material, local requirements and preconstruction evaluation by a licensed site evaluator or professional engineer. |
| Distinct professional roles | [TCEQ OSSF licensing](https://www.tceq.texas.gov/licensing/licenses/ossflic) describes evaluator, installer, designated representative and maintenance credentials. |
| Proposed system and inputs | [TCEQ system selection](https://www.tceq.texas.gov/permitting/ossf/ossfsystems.html) evaluates treatment/disposal combinations and site conditions; a soil name or timed water reading is not a system approval. |
| Current rule check | [TCEQ's rules index](https://www.tceq.texas.gov/rules/indxpdf.html) directs readers to the Secretary of State. The live rule text was not independently retrieved in this review. No numeric rule table is implemented here. |
| Lake jurisdiction question | [BRA lake regulations, §17.A](https://brazos.org/about-us/reservoirs/possum-kingdom-lake/lake-regulations) directs OSSF coordination with the lake office in BRA jurisdiction. A proximity response only prompts a question; the tool does not draw the jurisdiction boundary. |

The worksheet's record fields and sequence are project recommendations for organizing a discussion, not a complete official application or a mandatory process for every work type. For repairs, changed use or property review, ask which requirements apply before treating a new-construction workflow as applicable.

No directory entry confirms parcel jurisdiction. Use the current authority response for contact, application, local order, fee category, inspection sequence and final operating documents. This repository intentionally does not copy officer names, phone numbers, fee amounts or approval timelines into generated checklists.

## Using the worksheet

1. Record the parcel and proposed work, with survey/location references.
2. Identify the office responsible for that parcel and retain its dated response.
3. Gather or arrange the evaluation and planning records relevant to the proposal.
4. Have the responsible reviewer establish the applicable component-specific separation entries, footnotes and dimensions.
5. Obtain the current application packet and confirm what applies to this work.
6. Record the required authorization, inspection/covering directions and change process.
7. Keep final documents and ongoing obligations with the property record.

These steps organize questions. None is automatically checked off when inputs are supplied. A report reference is not proof that the report is adequate, and a recorded authority response is not independently verified by the generator.
